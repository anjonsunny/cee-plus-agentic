CEE+ Agentic — how the system actually flows

Two staged loops and a two-route petition. Read color as authority: every part either flags, measures, or advises — and only reflection speaks to the model.

Stages Stage 1 · Perception Stage 2 · Assessment Petition Authority FLAG · triggers a fix MEASURE · informs ADVISE · never overwrites DEV-only · never touches the run
The one rule that makes the chart readable: no component ever overwrites the answer. Code checks FLAG problems, probes MEASURE stability, judges ADVISE — but only the reflection loop carries any of it back to the model, and only the model revises its own answer. The petition is the one exception that may re-open an earlier stage.

MEASURE Probes → measured uncertainty

5 re-asks at temp 0.7. How much the model's own answer wobbles when asked again.
Granular. A vote per field and per entity ("dust in threats 2/5"). Splits > 0.2 point reflection at the exact shaky entity.
Weak-reason floor. A reason that never names the declared state is flagged for reflection (round 1 only — no rumination).
Geometry. Box math nominates who is near a hazard (overlap %, gap px). It suggests, never convicts.
Self-reported confidence is recorded but never trusted (it's a flat 0.95).

ADVISE Judges (llama3.1 · different family)

Runoff. When uncertainty is high, blind-judges the model's top-2 own readings. Winner becomes context for reflection — not the answer.
Pairwise. Blind pre-vs-post: did reflection actually help? Runs only when the decision truly changed (prose-only tweaks are skipped, so ties never pollute the record).
Rubric R1/R2. On demand: does each reason cite the declared state (R1) and a specific mechanism (R2)? Scores reason quality.
All three flag & measure. None may overwrite. Authority is earned per-utterance, not granted by role.

Reflection loop · how it carries the message

Triggers gather from all three columns → each is quoted back with its rulebook rule + the evidence (never "you were wrong", never the right answer). If the answer changes, probes re-run for a fresh uncertainty reading.
Stops: clean · STOOD (model justified holding) · cap · capitulation-guard. Open watch: "reflection jitter" — uncertainty can rise when reflection installs a claim the model's own probes don't reproduce.

PETITION

Router — re-open a stage, but only with cause

runs at most once · fires only if a ★ check survived reflection, or a caption ticket stood
The routing question:  where does the evidence point — at the facts, or at the sorting?
ROUTE A the entity list may be wrong → re-look the IMAGE
Chosen when the record can't support the verdict: a caption noun nobody found stood, or the verdict wants a danger source but the record has no hazard at all.
  • Re-asks Qwen-VL to look again (non-leading: shows the previous answer + the problem, invites "unchanged if you stand by it").
  • Two-witness merge — an added entity only joins if GroundingDINO also grounds it.
  • No-erasure — anything the second look drops is kept and logged as a dispute.
  • Cascade: both stages re-run on the merged record.
ROUTE B the facts are fine, the sorting is wrong → re-ask the QUESTION
Chosen when the record already holds a legal hazard and the states are right, but something is in the wrong list (e.g. a trapped man placed in threats).
  • One fresh re-ask of the assessment question — no image, no dialogue history (that channel is what caused the error).
  • Shows the previous answer + the problems + the rules; "return unchanged if you stand by it".
  • The shared record is never touched. One model call, then done.
